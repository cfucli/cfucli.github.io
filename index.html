cfucli

One real terminal that two people on different machines can both watch and type into.

No inbound port. No VPN. No admin rights on either side.

A shell runs on a machine and a window there shows it. Somebody you invite sees the same shell and can type into it. You are never locked out, you watch every keystroke as it happens, and one key takes control back.

It is for the times when explaining the problem over the phone is slower than letting the other person just do it.

Both ends dial outbound to a rendezvous, which is what lets it cross NAT and corporate firewalls without anyone opening a port or installing a VPN. When both ends are on the same machine it skips the rendezvous entirely and runs over a loopback socket, so nothing goes near the internet at all.

Get it

Download for Windows Source on GitHub

Version 0.1, Windows x64, 149 MB. Needs JDK 25 on your PATH and nothing else. Unzip it anywhere and run the included install.cmd — no step needs an administrator.

Two programs

cfucliapp

The window. Share this machine's shell, or join a session someone is sharing. Also the tray manager.

cfucli

The command line. Drives the same shell with exact exit codes and stdout and stderr kept apart, so an agent can use it.

In thirty seconds

# a shell on this machine, in a window you can watch
cfucli console --node work
cfucli exec    --node work "dir"
cfucli tail    --node work -n 40 -f

# share this machine - it prints an id and a one-time password
cfucliapp --host

# join what someone else is sharing, then drive it
cfucli join <id> -p <password> --node far
cfucli exec --node far "dir"

cfucli guide prints the full manual in the terminal.

What it does about safety

The one-time password authenticates an X25519 exchange rather than being the key itself, so every visit gets its own traffic key and a password recovered afterwards opens nothing that was recorded. Frames are AES-256-GCM. The rendezvous carries routing and liveness only — never command text, never output.

The host approves a viewer before they are admitted, refuses on silence, and can lock or restrict the far end at any moment without ending the session. A shared session also expires on its own: fifteen minutes idle, four hours absolute. A channel into someone's machine that never closes itself is a backdoor whatever it was built for.
